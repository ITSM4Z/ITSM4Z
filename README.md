## About Me

I'm a **Computer Science student at Umm Al-Qura University** focused on **Backend Engineering, Distributed Systems, and DevOps**. 

I approach software from an infrastructure-first mindset: understanding how operating system primitives, network sockets, and database query planners operate before abstracting them away. My current engineering work revolves around designing structured REST APIs, optimizing relational databases, and containerizing application runtimes.

* ⚙️ **Systems Approach:** Connecting core CS principles (process scheduling, TCP/IP, memory models) directly to production-style backend architecture.
* 🛠️ **Hands-on Stack:** Building services in Go, Java (Spring), and Python backed by PostgreSQL and MySQL.
* 🎯 **Objective:** Seeking **Software Engineering (Backend) / Cloud & DevOps Internships** where I can contribute to production codebases, write resilient services, and learn from senior engineers.
