<summary><b>Custom API Gateway in Go</b></summary>

<br/>

> A lightweight reverse proxy and API gateway built from scratch using Go's standard library to learn networking primitives, concurrency, and fault tolerance.

| Attribute | Detail |
|---|---|
| **Focus** | **Systems & Backend Engineering** |
| **Stack** | Go (`net/http`, `httputil`) · Concurrency (`sync.RWMutex`) · REST |
| **Repository** | [github.com/ITSM4Z/High-Performance-API-Gateway](https://github.com/ITSM4Z/High-Performance-API-Gateway) *(update link if needed)* |

**What I Built:**
- **Reverse Proxy & Dynamic Router:** Built a custom router with longest-prefix matching and shared TCP connection pooling (`http.Transport`) to forward traffic across multiple backend services.
- **Token Bucket Rate Limiter:** Wrote per-IP rate limiting middleware protected by mutexes, plus a background cleanup goroutine to evict idle clients from memory.
- **Circuit Breaker:** Implemented a 3-state machine (`Closed`, `Half-Open`, `Open`) that tracks downstream `5xx` errors and fails fast when a backend service goes down.
